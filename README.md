# SIGIP-CI

Observatoire géospatial des investissements publics de Côte d’Ivoire.

## Démarrage

```bash
npm install
cp .env.example .env.local
npm run dev
```

Les données visibles dans la première version sont fictives et explicitement identifiées comme données de démonstration.

## Isolement

Ce dépôt cible exclusivement le projet Supabase `ydnknrlgepzyedjzwfwo` et le futur projet Vercel `sigip-ci`. Aucun fichier, secret, déploiement ou migration d’un autre produit ne doit être réutilisé.
